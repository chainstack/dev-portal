Prepares Avalanche, World Chain, and Mantle deployments for mandatory mainnet hardforks, adds Plasma Aquila upgrade support ahead of its mainnet activation, and updates client images with a security fix and compatibility improvements across the catalog.

## Mandatory hardfork readiness

Avalanche, World Chain, and Mantle deployments now run client versions required for the Helicon, Karst, and Elysium hardforks. Avalanche's Helicon hardfork activates on mainnet today, September 22, 2026, at 15:00 UTC, and nodes not upgraded beforehand will diverge from the network.

## Plasma Aquila upgrade

Plasma deployments now configure the Aquila protocol upgrade automatically. Aquila has already activated on Plasma testnet and activates on Plasma mainnet at block 33,300,000.

## Breaking RPC changes

Avalanche removes the admin, warp, and personal JSON-RPC namespaces and several debug methods, OP Stack's optimism_syncStatus drops cross_unsafe_l2, and Starknet's pathfinder now disconnects WebSocket clients that stop answering keepalive pings.

## Improvements and fixes

- Fixes a deposit-transaction security issue on OP Stack reth clients.
- Updates Sui, Arbitrum, Starknet, TRON, Sonic, Tempo, and Solana client images for compatibility and reliability.
