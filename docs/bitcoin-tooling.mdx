## JSON-RPC API

Interact with your Bitcoin nodes using [JSON-RPC API](https://en.bitcoin.it/wiki/API_reference_\(JSON-RPC\)#JSON-RPC).

Use [curl](https://curl.haxx.se) or [Postman](https://www.getpostman.com) to invoke [Bitcoin API methods](https://bitcoin.org/en/developer-reference#bitcoin-core-apis).

To get basic network information from your Bitcoin node HTTPS endpoint, call `getblockchaininfo`:

<CodeGroup>
  ```bash cURL
  curl YOUR_CHAINSTACK_ENDPOINT -d '{"method":"getblockchaininfo","params":[],"id":1}'
  ```
</CodeGroup>

where YOUR\_CHAINSTACK\_ENDPOINT is your node HTTPS endpoint protected either with the key or password

## Signet Testnet and Testnet4

Signet Testnet and Testnet4 endpoints take the same JSON-RPC calls as Bitcoin Mainnet. Before your application sends transactions, check that `chain` in `getblockchaininfo` is `signet` or `testnet4`, because testnet addresses look the same on every testnet. For network parameters and how the testnets differ, see [Bitcoin testnets](/docs/bitcoin-testnets).

### Python

Install [requests](https://pypi.org/project/requests/):

<CodeGroup>
```shell Shell
pip install requests
```
</CodeGroup>

<CodeGroup>
```python main.py
import requests

ENDPOINT = "YOUR_CHAINSTACK_ENDPOINT"


def rpc(method, params=None):
    response = requests.post(
        ENDPOINT,
        json={"jsonrpc": "1.0", "id": 1, "method": method, "params": params or []},
    )
    body = response.json()
    if body.get("error"):
        raise RuntimeError(body["error"]["message"])
    return body["result"]


info = rpc("getblockchaininfo")
print("Chain:", info["chain"])
print("Blocks:", info["blocks"])

fee = rpc("estimatesmartfee", [6])
if "feerate" in fee:
    print("Fee rate (BTC/kvB):", fee["feerate"])
else:
    mempool = rpc("getmempoolinfo")
    print("No estimate for 6 blocks; minimum fee (BTC/kvB):", mempool["mempoolminfee"])
```
</CodeGroup>

On Testnet4, `estimatesmartfee` often has no estimate for short targets, so the `main.py` example falls back to the node's minimum mempool fee. See [Fee estimation on Testnet4](/docs/bitcoin-testnets#fee-estimation-on-testnet4).

<Note>
  python-bitcoinlib 0.12.2 rejects HTTPS URLs in `bitcoin.rpc.Proxy` with `Unsupported URL scheme 'https'`, so send JSON-RPC to a Chainstack endpoint with an HTTP client such as requests.
</Note>

### JavaScript

Install [bitcoinjs-lib](https://github.com/bitcoinjs/bitcoinjs-lib) with its key-pair dependencies. The example uses the built-in `fetch` from Node.js 18 or later.

<CodeGroup>
```shell Shell
npm install bitcoinjs-lib ecpair tiny-secp256k1
```
</CodeGroup>

<CodeGroup>
```javascript index.mjs
import * as bitcoin from "bitcoinjs-lib";
import { ECPairFactory } from "ecpair";
import * as ecc from "tiny-secp256k1";

const ENDPOINT = "YOUR_CHAINSTACK_ENDPOINT";

async function rpc(method, params = []) {
  const response = await fetch(ENDPOINT, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ jsonrpc: "1.0", id: 1, method, params }),
  });
  const body = await response.json();
  if (body.error) throw new Error(body.error.message);
  return body.result;
}

const { chain, blocks } = await rpc("getblockchaininfo");
console.log("Chain:", chain, "Blocks:", blocks);

const ECPair = ECPairFactory(ecc);
const keyPair = ECPair.makeRandom({ network: bitcoin.networks.testnet });
const { address } = bitcoin.payments.p2wpkh({
  pubkey: keyPair.publicKey,
  network: bitcoin.networks.testnet,
});
console.log("Address:", address);

const result = await rpc("validateaddress", [address]);
console.log("Valid on", chain + ":", result.isvalid);
```
</CodeGroup>

bitcoinjs-lib has no separate Signet Testnet or Testnet4 network, and `networks.testnet` produces `tb1` addresses that are valid on both. On a Testnet4 endpoint, the `index.mjs` example prints `Chain: testnet4`, a new `tb1q` address, and `Valid on testnet4: true`.

## Python

Work with Bitcoin from your Python application.

1. Install [bitcoincli](https://github.com/chainstack/bitcoincli).
2. Configure the client to use `host` and `port` of the node HTTPS endpoint, the corresponding node `username`, and `password`:

   <CodeGroup>
     ```python Python
     from bitcoincli import Bitcoin

     host = "nd-123-456-789.p2pify.com"
     port = "443"
     username = "user-name"
     password = "pass-word-pass-word-pass-word"

     bitcoin = Bitcoin(username, password, host, port)
     ```
   </CodeGroup>
3. Invoke any methods from the [Bitcoin API specification](https://bitcoin.org/en/developer-reference#bitcoin-core-apis):

   <CodeGroup>
     ```python Python
     info = bitcoin.getblockchaininfo()
     print(info)
     ```
   </CodeGroup>
