Our pricing is simple: 1 RU per full request, 2 RUs per archive. For which EVM methods are full vs archive, see [Request units — EVM methods affected by block age](/docs/request-units#evm-methods-affected-by-block-age).

Elysium is an Arbitrum Orbit chain from Kinetiq that settles to HyperEVM and uses HYPE for gas. Chainstack serves Elysium Testnet (chain ID `99801`) on [Nitro](https://github.com/OffchainLabs/nitro), the Arbitrum client. The availability below applies to Elysium Testnet on Global Nodes.

## Tracing

Tracing is served through the `debug_*` namespace — `debug_traceTransaction`, `debug_traceBlockByNumber`, `debug_traceBlockByHash`, and `debug_traceCall` — back to genesis. They accept the default native tracers (`callTracer`, `prestateTracer`, `4byteTracer`, and `noopTracer`) and the struct/opcode logger. `flatCallTracer`, `muxTracer`, and `erc7562Tracer` return the [disabled tracer error](/docs/limits#disabled-tracer-error).

The Parity-style `arbtrace_*` and `trace_*` namespaces are not exposed and return `-32601`. See [Debug and trace APIs](/docs/debug-and-trace-apis#elysium).

## Pending transactions are accepted but never delivered

Elysium has a single sequencer and no public mempool. `eth_newPendingTransactionFilter` returns a filter ID and `eth_subscribe("newPendingTransactions")` returns a subscription ID, but neither delivers a transaction, including the transactions you send through the same endpoint.

`txpool_status` returns `-32601`. `txpool_content` and `txpool_inspect` return `-32601` too, because Global Nodes do not serve them on any EVM chain. See [What gives you mempool access](/docs/mempool-configuration#what-gives-you-mempool-access).

## eth\_getProof window

`eth_getProof` returns a proof only for blocks less than 127 behind the tip. A request for an older block returns `-32000 historical state <state root> is not available`. See [EVM `eth_getProof` history limits](/docs/limits#evm-eth_getproof-history-limits).
