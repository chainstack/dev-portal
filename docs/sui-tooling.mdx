Get started with a [reliable Sui RPC endpoint](https://chainstack.com/build-better-with-sui/) to use the tools below. Your Chainstack Sui node serves gRPC, and Sui Mainnet Global Nodes also serve GraphQL on the same endpoint.

<Warning>
  Sui removes JSON-RPC from the full node in v1.82. Sui Testnet nodes no longer serve JSON-RPC, and Sui Mainnet nodes stop serving it with the v1.82 upgrade — see [Migrate Sui from JSON-RPC to gRPC and GraphQL](/docs/sui-migrate-json-rpc-to-grpc).
</Warning>

## Extended history

Sui Global Nodes are [Extended](/docs/extended-nodes). The node holds a window of checkpoints from `lowestAvailableCheckpoint` to the tip, not the full ledger from genesis. `LedgerService/GetServiceInfo` reports the current window — see [Checkpoint retention](/docs/sui-grpc-endpoint#checkpoint-retention) for how the window applies to gRPC and GraphQL.

## gRPC API

Sui nodes on Chainstack support gRPC for high-performance access. gRPC uses HTTP/2 and Protocol Buffers for binary serialization, which makes payloads smaller and adds server-side streaming — ideal for indexers, backends, and low-latency lookups. gRPC replaces JSON-RPC, which Sui removes from the full node in v1.82.

### Endpoint and authentication

Your Sui gRPC endpoint is `sui-mainnet.core.chainstack.com:443` (testnet: `sui-testnet.core.chainstack.com:443`), with TLS. Authenticate by passing your token in the `x-token` metadata header on every call. To find your endpoint and token on Chainstack, see [View node access and credentials](/docs/manage-your-node#view-node-access-and-credentials).

### Explore with grpcurl

Sui gRPC has server reflection enabled, so [grpcurl](https://github.com/fullstorydev/grpcurl) can list services and call methods without compiling proto files:

<CodeGroup>
  ```bash List services
  grpcurl -H "x-token: YOUR_X_TOKEN" \
    sui-mainnet.core.chainstack.com:443 \
    list
  ```

  ```bash Node and chain info
  grpcurl -H "x-token: YOUR_X_TOKEN" \
    sui-mainnet.core.chainstack.com:443 \
    sui.rpc.v2.LedgerService/GetServiceInfo
  ```
</CodeGroup>

The node exposes six `sui.rpc.v2` services:

| Service | Use it for |
| --- | --- |
| `LedgerService` | Checkpoints, objects, transactions, epochs, and node info |
| `StateService` | Balances, coins, owned objects, and dynamic fields |
| `TransactionExecutionService` | Executing and simulating transactions |
| `SubscriptionService` | Streaming checkpoints |
| `MovePackageService` | Move packages, modules, functions, and datatypes |
| `NameService` | SuiNS name resolution |

### gRPC from code

In TypeScript, use the official `@mysten/sui` SDK. Its default gRPC-Web transport works against Chainstack over HTTPS — including from the browser — so the simplest setup needs only your node URL as `baseUrl`. For server-side apps that prefer native gRPC over HTTP/2, pass a native transport instead. From other languages, generate typed stubs from [Sui's proto definitions](https://github.com/MystenLabs/sui/tree/main/crates/sui-rpc-api/proto) and connect over native gRPC. Authenticate with your node's `x-token` — carried in the endpoint URL, or as `x-token` metadata on native-gRPC calls — and use recent client versions — `@mysten/sui` 2.16+ and `@grpc/grpc-js` 1.14+ — since older releases produce intermittent gRPC errors under load.

<CodeGroup>
  ```typescript TypeScript (gRPC-Web)
  // npm install @mysten/sui
  // Default gRPC-Web transport over HTTPS — works in the browser and in Node.js.
  import { SuiGrpcClient } from '@mysten/sui/grpc';

  const client = new SuiGrpcClient({
    network: 'mainnet',
    baseUrl: 'YOUR_CHAINSTACK_SUI_HTTPS_ENDPOINT',
  });

  const gasPrice = await client.core.getReferenceGasPrice();
  console.log(gasPrice.referenceGasPrice);
  ```

  ```typescript TypeScript (native gRPC)
  // npm install @mysten/sui @protobuf-ts/grpc-transport @grpc/grpc-js
  // Native gRPC over HTTP/2 — server runtimes only.
  import { SuiGrpcClient } from '@mysten/sui/grpc';
  import { GrpcTransport } from '@protobuf-ts/grpc-transport';
  import { ChannelCredentials } from '@grpc/grpc-js';

  const client = new SuiGrpcClient({
    network: 'mainnet',
    transport: new GrpcTransport({
      host: 'sui-mainnet.core.chainstack.com:443',
      channelCredentials: ChannelCredentials.createSsl(),
      meta: { 'x-token': 'YOUR_X_TOKEN' },
    }),
  });

  const gasPrice = await client.core.getReferenceGasPrice();
  console.log(gasPrice.referenceGasPrice);
  ```

  ```python Python
  import grpc

  channel = grpc.secure_channel(
      "sui-mainnet.core.chainstack.com:443",
      grpc.ssl_channel_credentials(),
  )
  metadata = (("x-token", "YOUR_X_TOKEN"),)

  # With stubs generated from Sui's protos:
  # stub = ledger_service_pb2_grpc.LedgerServiceStub(channel)
  # resp = stub.GetServiceInfo(
  #     ledger_service_pb2.GetServiceInfoRequest(), metadata=metadata
  # )
  # print(resp.checkpoint_height)
  ```

  ```javascript Node.js
  const grpc = require('@grpc/grpc-js');

  const credentials = grpc.credentials.createSsl();
  const metadata = new grpc.Metadata();
  metadata.add('x-token', 'YOUR_X_TOKEN');

  // With stubs generated from Sui's protos:
  // const client = new LedgerServiceClient(
  //   'sui-mainnet.core.chainstack.com:443', credentials);
  // client.getServiceInfo({}, metadata, (err, resp) => {
  //   console.log(resp.checkpointHeight);
  // });
  ```

  ```go Go
  package main

  import (
      "context"

      "google.golang.org/grpc"
      "google.golang.org/grpc/credentials"
      "google.golang.org/grpc/metadata"
  )

  func main() {
      creds := credentials.NewTLS(nil)
      conn, err := grpc.Dial(
          "sui-mainnet.core.chainstack.com:443",
          grpc.WithTransportCredentials(creds),
      )
      if err != nil {
          panic(err)
      }
      defer conn.Close()

      ctx := metadata.AppendToOutgoingContext(
          context.Background(), "x-token", "YOUR_X_TOKEN",
      )
      _ = ctx // pass ctx to your generated gRPC client calls
  }
  ```
</CodeGroup>

<Info>
  The default gRPC-Web transport works in both the browser and server runtimes, so it is the simplest choice for most apps. The native gRPC transport (HTTP/2) is server-side only — use it when you specifically need native gRPC.
</Info>

## GraphQL API

Sui Mainnet Global Nodes serve Sui's GraphQL RPC at `YOUR_CHAINSTACK_ENDPOINT/graphql`, with the same auth token as your HTTPS endpoint. Use GraphQL for filtered, paginated reads — transactions by address, events by type, objects by owner and type — that have no gRPC equivalent. GraphQL is not available on Sui Testnet.

In TypeScript, use `SuiGraphQLClient` from the official `@mysten/sui` SDK:

```typescript TypeScript
// npm install @mysten/sui
import { SuiGraphQLClient } from '@mysten/sui/graphql';
import { graphql } from '@mysten/sui/graphql/schema';

const client = new SuiGraphQLClient({
  url: 'YOUR_CHAINSTACK_ENDPOINT/graphql',
  network: 'mainnet',
});

const result = await client.query({
  query: graphql(`
    query {
      checkpoint {
        sequenceNumber
        timestamp
      }
    }
  `),
});
console.log(result.data);
```

Filtered queries and events keep a shorter history window than point lookups. For authentication options, filters, history windows, and query limits, see [Sui GraphQL endpoint](/docs/sui-graphql-endpoint).

## Sui TypeScript SDK

The [Sui TypeScript SDK](https://github.com/MystenLabs/ts-sdks/tree/main/packages/sui) is the official SDK for building Sui applications. Use its gRPC client, `SuiGrpcClient`, for reads and transactions, and `SuiGraphQLClient` for filtered queries — see [GraphQL API](#graphql-api).

### Installation

```bash
npm install @mysten/sui
```

<Note>
The SDK's JSON-RPC client, `SuiJsonRpcClient` from `@mysten/sui/jsonRpc`, stops working when JSON-RPC is removed. `SuiGrpcClient` covers the same reads and transactions through methods such as `getObject`, `listOwnedObjects`, `getBalance`, and `signAndExecuteTransaction`. See the [SDK 2.0 migration guide](https://sdk.mystenlabs.com/sui/migrations/sui-2.0).
</Note>

### Basic usage

<CodeGroup>
  ```typescript Connection
  import { SuiGrpcClient } from '@mysten/sui/grpc';

  // Connect to your Chainstack node
  const client = new SuiGrpcClient({
    network: 'mainnet',
    baseUrl: 'YOUR_CHAINSTACK_SUI_HTTPS_ENDPOINT',
  });

  // Get the reference gas price for the current epoch
  const { referenceGasPrice } = await client.getReferenceGasPrice();
  console.log('Reference gas price:', referenceGasPrice);
  ```

  ```typescript Query Objects
  import { SuiGrpcClient } from '@mysten/sui/grpc';

  const client = new SuiGrpcClient({
    network: 'mainnet',
    baseUrl: 'YOUR_CHAINSTACK_SUI_HTTPS_ENDPOINT',
  });

  // Get objects owned by an address
  const { objects } = await client.listOwnedObjects({
    owner: 'SUI_ADDRESS',
    limit: 10,
  });

  for (const object of objects) {
    console.log(object.objectId, object.type);
  }
  ```

  ```typescript Send Transaction
  import { SuiGrpcClient } from '@mysten/sui/grpc';
  import { Transaction } from '@mysten/sui/transactions';
  import { Ed25519Keypair } from '@mysten/sui/keypairs/ed25519';

  const client = new SuiGrpcClient({
    network: 'mainnet',
    baseUrl: 'YOUR_CHAINSTACK_SUI_HTTPS_ENDPOINT',
  });

  const keypair = Ed25519Keypair.generate();
  const tx = new Transaction();

  // Replace with your object ID and recipient address
  const objectId = 'YOUR_OBJECT_ID';
  const recipient = 'RECIPIENT_ADDRESS';

  // Add transaction commands
  tx.transferObjects([objectId], recipient);

  // Sign and execute
  const result = await client.signAndExecuteTransaction({
    signer: keypair,
    transaction: tx,
  });
  ```
</CodeGroup>

## Sui Rust SDK

The [`sui-rpc`](https://github.com/MystenLabs/sui-rust-sdk/tree/master/crates/sui-rpc) crate from Mysten Labs' Sui Rust SDK is a gRPC client for Sui, published on crates.io.

### Installation

Add to your `Cargo.toml`:

```toml
sui-rpc = "0.4"
tokio = { version = "1", features = ["full"] }
anyhow = "1"
```

### Basic usage

```rust
use sui_rpc::client::{Client, HeadersInterceptor};
use sui_rpc::proto::sui::rpc::v2::GetServiceInfoRequest;

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let mut headers = HeadersInterceptor::new();
    headers.headers_mut().insert("x-token", "YOUR_X_TOKEN".parse()?);

    let mut client = Client::new("https://sui-mainnet.core.chainstack.com")?.with_headers(headers);

    let info = client
        .ledger_client()
        .get_service_info(GetServiceInfoRequest::default())
        .await?
        .into_inner();
    println!("Chain: {:?}, checkpoint: {:?}", info.chain, info.checkpoint_height);

    Ok(())
}
```

## Python SDK (pysui)

[pysui](https://github.com/FrankC01/pysui) is a community-maintained Python SDK for Sui. pysui 1.x connects over gRPC and GraphQL, and its gRPC client is async. pysui reads its connection settings from a configuration folder, so the example creates one with a Chainstack profile on the first run and passes your x-token as a header on every call.

### Installation

```bash
pip install pysui
```

### Basic usage

```python
import asyncio
from pathlib import Path

from pysui import PysuiConfiguration
from pysui.sui.sui_common.config.confgroup import NetworkType
from pysui.sui.sui_grpc.pgrpc_clients import GrpcProtocolClient
import pysui.sui.sui_grpc.pgrpc_requests as rn

CONFIG_DIR = Path("~/.pysui-chainstack").expanduser()

# Create a pysui configuration with a Chainstack profile on first run
try:
    cfg = PysuiConfiguration(from_cfg_path=str(CONFIG_DIR), group_name="chainstack")
except ValueError:
    cfg = PysuiConfiguration.initialize_config(
        in_folder=CONFIG_DIR,
        init_groups=[{"name": "chainstack", "make_active": True}],
    )
    cfg.new_profile(
        profile_name="mainnet",
        url="https://sui-mainnet.core.chainstack.com:443",
        network_type=NetworkType.PRODUCTION,
        make_active=True,
        in_group="chainstack",
    )


async def main():
    client = GrpcProtocolClient(pysui_config=cfg, default_header={"x-token": "YOUR_X_TOKEN"})
    result = await client.execute_grpc_request(request=rn.GetServiceInfo())
    if result.is_ok():
        print(f"Latest checkpoint: {result.result_data.checkpoint_height}")
    else:
        print(result.result_string)
    await client.close()


asyncio.run(main())
```

For a complete pysui program, see [Sui: On-chain validator analytics with pysui](/docs/sui-on-chain-validator-analytics-with-pysui).

## Go SDK

The [Sui Go SDK](https://github.com/block-vision/sui-go-sdk) from BlockVision provides Go language bindings for Sui, including a gRPC client. The client dials without TLS by default, so pass TLS credentials for your Chainstack endpoint.

### Installation

```bash
go get github.com/block-vision/sui-go-sdk
```

### Basic usage

```go
package main

import (
    "context"
    "fmt"
    "log"

    "github.com/block-vision/sui-go-sdk/common/grpcconn"
    v2 "github.com/block-vision/sui-go-sdk/pb/sui/rpc/v2"
    "google.golang.org/grpc"
    "google.golang.org/grpc/credentials"
)

func main() {
    client := grpcconn.NewSuiGrpcClientWithAuth(
        "sui-mainnet.core.chainstack.com:443",
        "YOUR_X_TOKEN",
        grpcconn.WithDialOptions(grpc.WithTransportCredentials(credentials.NewTLS(nil))),
    )
    defer client.Close()

    ctx := context.Background()

    ledger, err := client.LedgerService(ctx)
    if err != nil {
        log.Fatal(err)
    }

    info, err := ledger.GetServiceInfo(ctx, &v2.GetServiceInfoRequest{})
    if err != nil {
        log.Fatal(err)
    }

    fmt.Printf("Chain: %s, checkpoint: %d\n", info.GetChain(), info.GetCheckpointHeight())
}
```
