title: "TON methods"
description: "Complete TON blockchain API methods reference. Includes v2, v3, and v4 endpoints for addresses, transactions, blocks, NFTs, Jettons, and smart contracts."
---

See also [interactive TON API call examples](/reference/getting-started-ton).

Our pricing is simple: 1 RU per full request, 2 RUs per archive. For which TON methods are full vs archive, see [Request units — TON method scope](/docs/request-units#ton-method-scope).

The v4 routes are served on Global Nodes under the `/api/v4` path. For the v4 endpoint format and examples, see [TON API v4](/docs/ton-choosing-v2-or-v3#ton-api-v4).
