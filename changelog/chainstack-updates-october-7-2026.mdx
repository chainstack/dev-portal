---
title: "Chainstack updates: October 7, 2026"
description: "Multichain API lets you use one auth token across the Global Nodes and Dedicated Nodes you attach to a single endpoint."
---

**Multichain API**. You can now use one auth token across several chains. See [Use Multichain API](/docs/multichain-api) for the full guide. A multichain endpoint holds the [Global Nodes](/docs/global-elastic-node) and [Dedicated Nodes](/docs/dedicated-node) you attach to it, and its multichain auth token authorizes requests to every attached node. Instead of managing one auth token per node, you keep one secret in your environment variables or CI.

**Set up an endpoint**. On Chainstack, click **Multichain API** > **Create endpoint** and name the endpoint. On the endpoint page, click **Add node** to attach nodes. You can add or remove nodes at any time, and the multichain auth token stays the same. Under **Connection details**, select a node to copy its HTTPS and WSS endpoint URL, which already contains the multichain auth token.

**Multichain auth token**. The multichain auth token starts with `mt_`, and you can copy the full value from the endpoint page at any time. To replace the multichain auth token, create a new endpoint with the same nodes, update your applications, and delete the old endpoint. You can't rotate the multichain auth token of an existing endpoint.

**Attachment rules**. An endpoint can hold one Global Node per protocol and network and any number of Dedicated Nodes. You can't attach [Trader Nodes](/docs/trader-node). The same node can belong to several endpoints. When you delete a node on Chainstack, Chainstack removes the node from its endpoints, and the endpoints and their multichain auth tokens stay.

**Requests**. A request that uses the multichain auth token on a node that is not attached to the endpoint returns `401 Unauthorized`. Each request follows the rate limits and access rules of the node it targets.

**Delete an endpoint**. Click **Delete endpoint** to revoke the multichain auth token on every attached node. You can't undo the deletion.

**Availability**. Multichain API is available on every plan, including the Developer plan.
