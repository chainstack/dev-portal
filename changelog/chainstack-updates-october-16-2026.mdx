**Protocols**. X Layer is now available on Chainstack Global Nodes. X Layer is OKX's Ethereum L2 built on the OP Stack. You can deploy [Global Nodes](/docs/global-elastic-node) for X Layer Mainnet and Testnet, in Archive mode with debug and trace. [Dedicated Nodes](/docs/dedicated-node) for X Layer remain available. See [Networks](/docs/protocols-networks).
