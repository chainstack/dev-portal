title: "Chainstack updates: September 2, 2026"
description: "Starknet nodes are upgrading to Pathfinder v0.24.0 — a breaking change that requires WebSocket clients to answer server-initiated pings."
---

**Starknet**. Chainstack is upgrading Starknet nodes to [Pathfinder v0.24.0](https://github.com/equilibriumco/pathfinder/releases/tag/v0.24.0). This is a breaking change for WebSocket clients: the server now pings a connection that has gone quiet and closes it after two unanswered pings, so a client that does not reply to ping frames is disconnected 60 seconds after its last frame. A connection that sends nothing within 30 seconds of being established is also closed. Standard WebSocket libraries answer pings automatically and need no changes. HTTP JSON-RPC is unaffected, and the JSON-RPC API versions served do not change. See [Pathfinder WebSocket keepalive 0.24.0](/reference/starknet-pathfinder-0-24-0-websocket-keepalive) for the migration guide.
