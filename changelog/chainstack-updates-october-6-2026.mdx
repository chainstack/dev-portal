title: "Chainstack updates: October 6, 2026"
description: "The Chainstack MCP server gets a dependency refresh that resolves all open security advisories, a 30-minute idle-session timeout, and more memory headroom."
---

**MCP Server**. The [Chainstack MCP server](https://mcp.chainstack.com) has moved to the latest FastMCP 3.x and MCP Python SDK releases, which resolves every open security advisory in its dependency tree. One behaviour change comes with it: idle MCP sessions now close after 30 minutes of inactivity. If your client reconnects after a long pause, it receives a `404` on the old session and re-initializes; Claude Code, Cursor, Codex and other spec-compliant clients handle this automatically. We also raised the server's memory headroom to reduce restarts during traffic spikes. No tools were added or changed. Connect at `https://mcp.chainstack.com/mcp`, or see the [discovery page](https://mcp.chainstack.com) for per-client setup.
