---
title: "Chainstack updates: October 23, 2026"
description: "Every Chainstack MCP server tool now has a readable title and states how it behaves, and VS Code no longer asks you to review results from tools that return Chainstack's own docs, status and pricing."
---

**MCP Server**. The [Chainstack MCP server](https://mcp.chainstack.com) has been optimized with the following updates:

- Every tool has a readable title, such as **Create node** or **Search Chainstack docs**. Clients that display titles, such as VS Code, show it in place of the raw tool name.
- Every tool declares all four MCP annotation hints, which your AI client uses to decide when to ask you before a call. The hints say:
  - whether the tool only reads data
  - whether it can change or delete something
  - whether repeating a call is safe
  - whether its results can contain text from outside Chainstack
- Tools that return Chainstack's own content no longer trigger a result review in VS Code before your agent sees the output:
  - docs
  - platform status
  - pricing
  - deployment options
- Tools that return your project, node or organization data, and every tool that changes something, keep their review and approval prompts.

Connect at `https://mcp.chainstack.com/mcp`, or see the [discovery page](https://mcp.chainstack.com) for per-client setup.
