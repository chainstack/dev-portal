title: "Chainstack updates: October 12, 2026"
description: "The Chainstack MCP server now returns every project in organizations with more than 100, names the city for each deployment region, and tells your AI agent when a testnet faucet top-up is done."
---

**MCP Server**. The [Chainstack MCP server](https://mcp.chainstack.com) has these updates:

- `list_projects` returns every project in organizations with more than 100 projects. Previously, the second page of results repeated the first.
- Deployment options include `region_name`, the city for each region code, so your AI agent can match a location such as London without guessing codes.
- When the [Chainstack faucet](/docs/faucets) tops up an address through the MCP server, the response tells the agent that the funds were sent and not to request the same network again.
- The faucet tool states the cooldown: one top-up per network every 24 hours, refused if your organization or the destination address already got funds on that network.

Connect at `https://mcp.chainstack.com/mcp`, or see the [discovery page](https://mcp.chainstack.com) for per-client setup.
