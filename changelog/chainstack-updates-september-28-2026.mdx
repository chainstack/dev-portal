**Protocols**. Sui Global Nodes now serve the GraphQL RPC API on Mainnet, alongside gRPC and JSON-RPC on the same endpoint and auth token. GraphQL covers the flexible, filtered reads. Point your client at `/{token}/graphql`. Requests are billed at 1 RU each, the same as gRPC. GraphQL serves recent history (from January 2026 onward); for full-history reads, use gRPC or a Dedicated Node in Archive mode. See [Sui tooling](/docs/sui-tooling).
