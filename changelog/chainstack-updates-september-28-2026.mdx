**Protocols**. Sui Mainnet Global Nodes now serve the GraphQL RPC API at `/graphql`, alongside gRPC and JSON-RPC on the same endpoint and auth token. Use GraphQL for filtered, paginated reads — transactions by address, events by type, objects by owner and type — that have no gRPC equivalent. Each request is 1 RU, the same as gRPC. Point lookups and unfiltered lists reach back to January 2026; filtered transaction and event queries cover the most recent 90 days. See [Sui GraphQL endpoint](/docs/sui-graphql-endpoint).
