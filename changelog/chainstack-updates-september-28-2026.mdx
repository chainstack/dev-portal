**Protocols**. Sui Global Nodes now serve the GraphQL RPC API on Mainnet, alongside gRPC and JSON-RPC on the same endpoint and auth token. GraphQL covers the flexible, filtered reads — the former `suix_*` methods — that have no gRPC equivalent. Point your client at `/{token}/graphql`. See [Sui tooling](/docs/sui-tooling).
