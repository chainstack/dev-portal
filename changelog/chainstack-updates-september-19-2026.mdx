---
title: "Chainstack updates: September 19, 2026"
description: "Solana transaction v1 is live on Mainnet, and reading blocks or transactions now requires maxSupportedTransactionVersion set to 1."
---

**Protocols**. Solana [transaction v1](/docs/solana-transaction-v1) activated on Mainnet at the start of epoch 1035. Blocks now mix legacy, v0, and v1 transactions, and the per-transaction size limit is 4096 bytes instead of 1232.

If you read Solana data, pass `maxSupportedTransactionVersion: 1` to [getBlock](/reference/solana-getblock), [getTransaction](/reference/gettransaction), and [blockSubscribe](/reference/blocksubscribe-solana). At a lower value `getBlock` and `getTransaction` respond with error `-32015`, and `blockSubscribe` keeps streaming notifications that carry no block data.
