**Node auth token rotation**. You can now rotate a node's auth token on Chainstack without downtime. Generate a new auth token, update your applications while both auth tokens work, and then deactivate the old one. A rotation also replaces the node's username, password, and gRPC x-token. See [Rotate a node auth token](/docs/manage-your-node#rotate-a-node-auth-token).
