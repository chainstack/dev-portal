**Protocols**. Chainstack TON Global Nodes now serve TON API v4 — REST and WebSocket — alongside v2 and v3 on the same endpoint and auth token, on Mainnet and Testnet. v4 adds block-pinned, cacheable URLs for blocks, account state, and get-method calls, and WebSocket streams of new blocks and of the accounts changed in each block. See [TON API v4](/docs/ton-choosing-v2-or-v3#ton-api-v4).
