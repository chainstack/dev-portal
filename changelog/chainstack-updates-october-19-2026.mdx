**Protocols**. Zcash is now available on Chainstack Global Nodes. Zcash is a privacy-focused UTXO L1 with shielded transactions and a Bitcoin-style JSON-RPC API extended with `z_*` methods. You can deploy [Global Nodes](/docs/global-elastic-node) for Zcash Mainnet and Testnet, in Full mode, with transparent transaction history available back to the first block. See [Networks](/docs/protocols-networks).
