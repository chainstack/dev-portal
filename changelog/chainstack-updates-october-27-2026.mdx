**Avalanche**. Chainstack upgraded Avalanche [Global Nodes](/docs/global-elastic-node) on Mainnet and Fuji Testnet to [AvalancheGo v1.15.2](https://github.com/ava-labs/avalanchego/releases/tag/v1.15.2). This version removes the C-Chain method `avax.getAtomicTxStatus`, deprecated since v1.15.0, so use `avax.getAtomicTx` instead. `platform.getCurrentValidators` now returns `restakedValidationRewards` and `restakedDelegateeRewards` for auto-renewed validators. See [Avalanche Helicon network upgrade](/docs/avalanche-helicon-upgrade).
