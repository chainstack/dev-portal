## Parameters

* `transactionHash` — the hash of the transaction to retrieve the receipt for

## Response

* `result` — a receipt object, or `null` if no receipt was found:
  * `transactionHash` — the transaction hash
  * `blockHash` — hash of the block containing this transaction
  * `blockNumber` — block number containing this transaction
  * `from` — address of the sender
  * `to` — address of the receiver
  * `status` — `1` for success, `0` for failure
  * `gasUsed` — amount of gas used
  * `logs` — array of log objects
  * `effectiveGasPrice` — the gas price actually paid, in wei
  * `type` — transaction type: `0x0` legacy, `0x1` EIP-2930, `0x2` EIP-1559, or `0x4` EIP-7702

```javascript ethers.js
const ethers = require('ethers');
const NODE_URL = "CHAINSTACK_NODE_URL";

    const receipt = await provider.getTransactionReceipt("0xfc48f7c70e8ffaa46b1110dc43f32e90f65434a0949edab384d066c820c57ee2");
    console.log(receipt);
  };

getReceipt();
```

```python web3.py
from web3 import Web3

node_url = "CHAINSTACK_NODE_URL"
```
