Arc API method that returns the current gas price in wei. Arc pays gas in USDC, which is the native currency of the chain, so the price is denominated in wei with 18 decimals exactly as on Ethereum.

## `eth_gasPrice` code examples

<CodeGroup>
```javascript ethers.js
const ethers = require('ethers');
const NODE_URL = "CHAINSTACK_NODE_URL";
const provider = new ethers.JsonRpcProvider(NODE_URL);

const getGasPrice = async () => {
    const feeData = await provider.getFeeData();
    console.log(`Gas price: ${feeData.gasPrice} wei`);
  };

getGasPrice();
```
