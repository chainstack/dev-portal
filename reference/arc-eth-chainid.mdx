Arc API method that returns the chain ID of the current network. Arc Mainnet is `5042` (`0x13b2` in hexadecimal) and Arc Testnet is `5042002` (`0x4cef52`).

## Parameters

* `none`

## Response

* `result` — the chain ID encoded as hexadecimal (`0x13b2` for Arc Mainnet, `0x4cef52` for Arc Testnet)

## `eth_chainId` code examples

<CodeGroup>
```javascript ethers.js
const ethers = require('ethers');
const NODE_URL = "CHAINSTACK_NODE_URL";
const provider = new ethers.JsonRpcProvider(NODE_URL);

const getChainId = async () => {

  };
```
