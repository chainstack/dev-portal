Arc API method that returns the balance of a specific account in wei, the smallest denomination of the native token.

## Parameters

* `address` — the address to check the balance of
* `quantity or tag` — the block number in hex format or block tag (`latest`, `earliest`, `pending`, `safe`, `finalized`)

## Response

* `quantity` — the integer value of the current balance in wei

## `eth_getBalance` code examples

<CodeGroup>
```javascript ethers.js
const { JsonRpcProvider } = require("ethers");

const provider = new JsonRpcProvider("CHAINSTACK_NODE_URL");

async function call() {
  const result = await provider.send("eth_getBalance", ["0x40c4431d0a6a183a2f1e604744f4cf25d2aea8e6", "latest"]);
  console.log(result);
}

call();
```

```python web3.py
from web3 import Web3

node_url = "CHAINSTACK_NODE_URL"

result = web3.provider.make_request("eth_getBalance", ["0x40c4431d0a6a183a2f1e604744f4cf25d2aea8e6", "latest"])
print(result)
```
